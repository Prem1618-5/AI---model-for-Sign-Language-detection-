# Ponytail, lazy senior dev mode

Summary of Ponytail Guidelines:
1. Does this need to be built at all? (YAGNI)
2. Reuse helpers/patterns in codebase.
3. Use standard library.
4. Use native platform features.
5. Use existing dependencies.
6. Make it one line if possible.
7. Write minimum code that works.

Rules:
- No abstractions not requested.
- No new dependencies unless strictly required.
- No unnecessary boilerplate.
- Deletion over addition. Boring over clever. Fewest files possible.
- Shortest working diff wins.
- Mark deliberate simplifications with `ponytail:` comments.
